Kinerja model (AUC)

KLHK = Peta Rawan Karhutla KLHK. ★ = model utama; tebal = terbaik per baris. AUC 0,5 = acak, 1 = sempurna. Uji temporal: model dilatih dengan titik api 2015–2022 lalu diuji pada kejadian yang tidak dipakai melatih (2023–2025, 2026) dan pada area terbakar MODIS (sumber independen).

Tentang WebGIS ini

WebGIS untuk PjBL GD4103 Sistem Informasi Geografis 2026 (Teknik Geodesi dan Geomatika ITB), tema karhutla, fokus titik api di Provinsi Papua Selatan (Merauke, Mappi, Boven Digoel, Asmat).

Data terkini. Titik api 7 hari terakhir dari NASA FIRMS NRT (VIIRS S-NPP, NOAA-20, NOAA-21, MODIS Terra/Aqua) diunduh ulang otomatis setiap 6 jam oleh GitHub Actions, diberi atribut kecamatan, kelas bahaya, gambut, fungsi kawasan, dan perizinan.

Model. 12 parameter: tutupan lahan, curah hujan Agu–Nov, fraksi gambut, frekuensi genangan, jarak ke permukiman, jalan, sungai, kehilangan hutan 2013–2022, fungsi kawasan hutan, perizinan, elevasi, kemiringan. Tiga model: Rasio Frekuensi, AHP, Random Forest. Latih 2015–2022, uji 2023–2025 dan 2026.

Sumber data. NASA FIRMS; MODIS MCD64A1 (Microsoft Planetary Computer); BIG Satu Peta (gambut FEG, KHG, rawan karhutla KLHK, kawasan hutan, PBPH, izin sawit, PIPPIB, mangrove, sawah, kecamatan); ESA WorldCover 2021; Esri/IO LULC; Hansen GFC v1.13; JRC Global Surface Water; CHIRPS v3; Copernicus DEM; Peat-ML; GHSL 2025; WorldPop 2020 + Sensus Penduduk 2020 (BPS); OpenStreetMap; geoBoundaries.
